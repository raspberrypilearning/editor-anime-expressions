## Change colours and fonts

In `index.html`, change the style of your webpage.

```html filename="index.html" line_numbers="true" line_number_start="21" line_highlights="24"
    <!-- Include CSS style file -->

    <link href="style.css" rel="stylesheet" type="text/css" />
    <link href="vivid.css" rel="stylesheet" type="text/css" />

```

> [!TIP]
>
> Try out different styles for your webpage. Look at the other CSS files, and choose the one that you like the most.

## Now run your code

![The page with brightly coloured backgrounds and different fonts.](images/vivid_style.png)

Click the **Run** button and check that the page now has the colours and fonts from the new CSS file.
