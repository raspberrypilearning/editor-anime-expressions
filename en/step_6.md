## Style your page

![Clicking on the triangle next to line 3 to expand the head code.](images/step_2_collapse.gif)

In the next steps, you will use CSS to change the colours, fonts, and layout on your webpage.

Make the following changes to your code:

```html filename="index.html" line_numbers="true" line_number_start="21" line_highlights="23-24"
    <!-- Include CSS style file -->

    <link href="style.css" rel="stylesheet" type="text/css" />
    <link href="candy.css" rel="stylesheet" type="text/css" />
  </head>

```

> [!TIP]
>
> CSS is a style sheet language that defines the presentation of HTML documents, including layout, colours, fonts, and spacing.

> To collapse the `<head>` section after you have made the changes, click the arrow next to it.

## Now run your code

Now your page should look like this:

![On the page, the text is now in different fonts and the 'Facial expressions' section has a grey background and grey text.](images/style_changed.png)

Click the **Run** button and check that the page now uses the new background colours and fonts.
