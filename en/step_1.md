## Add a header

The starter project to the right has some code that has already been written for you.

Click on the small triangle next to line 3 to collapse the `<head>`.

![Clicking on the triangle next to line 3 to collapse the head.](images/step_2_collapse.gif)

Add in an `<h1>` tag with some text to add a header to your webpage.

> [!TIP]
>
> The `<h1>` tag is used to define the main heading of your webpage. It is like the title of a book.

Your code should look like this:

```html filename="index.html" line_numbers="true" line_number_start="27" line_highlights="30"
  <body>
    <!-- The page header code goes here -->
    <header>
      <h1>Draw anime with me</h1>
    </header>
```

> [!TIP]
>
> When you open a tag like `<h1>`, the Code Editor will automatically add a closing tag `</h1>` for you.

## Now run your code

Click the **Run** button and check that the page shows the "Draw anime with me" heading.
